# Contributing

Open an issue describing the problem before proposing a large behavior change.
Target `master` with pull requests. Follow BUILDING.md and run the Rust tests,
frontend tests, production build and applicable desktop/package checks.

Use synthetic fixtures. Do not submit game installation files, saved projects,
credentials, personal paths or screenshots containing private information.
Include a focused regression test when changing parsing, arithmetic, persistence,
export or migration behavior. Document visible changes in the manual.

By submitting an original contribution, you agree to license it under
AGPL-3.0-only, the project's license. Preserve third-party notices.
