# Security policy

Only the latest published release is supported for security fixes.

Report vulnerabilities through the repository's Security tab when private
reporting is available. Otherwise open an issue requesting a private reporting
channel without including exploit instructions, credentials or private data.
Do not upload game files or saved projects with sensitive information.

The editor reads local files and exports separate mods. Report source-directory
writes, unsafe path handling, renderer isolation failures or malformed-input
crashes with a minimal synthetic example where possible.
