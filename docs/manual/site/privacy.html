EU5 Population Editor 1.0.3

Privacy, data and licensing

The editor processes game data locally and does not require an account or online editing service. The manual also keeps search queries in your browser.

Files and network access

The application reads the game installation and creates projects, reports and exported mods only through the documented local workflows. It does not modify vanilla game files. Settings and cache data use the application user-data directory.

Normal editing has no telemetry, remote content or background model/data downloads. Manual opens the bundled local edition in a separate application window without a local HTTP server. Choosing an explicit online-manual, repository, download or issue link opens an external website in your browser. That website's own network and privacy behavior applies.

The generated manual uses local styles, scripts, images and system fonts. Its browser search is local. The hosted manual stores its chosen color-theme preference; the in-app manual follows the application's appearance setting and stores no separate theme choice. Hosting providers may process ordinary access requests when you visit the hosted site.

Backups and sharing

Keep backups of native projects, especially before migration. Reports and projects can contain location identifiers, game-derived data and your edits. Inspect them before sharing. Remove personal filesystem paths from issue reports and screenshots.

The source repository and release packages do not include proprietary game files. Users supply their own installed game data. An exported mod can include game-derived population content; this software's license does not grant rights over that game content.
