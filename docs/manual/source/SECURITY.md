# Security

The current 1.0.x line is supported. The generated manual is a static website and does not accept uploads, credentials or server-side submissions.

For sensitive vulnerability details, use GitHub's private vulnerability reporting feature when it is available for this repository. Do not post exploit details, credentials or personal data in a public issue. If private reporting is unavailable, open an issue requesting a private reporting channel without including the sensitive details.

For a vulnerability in the application itself, use the security guidance in the EU5-Population-Editor repository. Ordinary documentation corrections belong in the manual issue tracker.
